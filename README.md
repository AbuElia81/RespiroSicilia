# Respiro Sicilia

### 👉 [Zur Seite: abuelia81.github.io/RespiroSicilia](https://abuelia81.github.io/RespiroSicilia/)

[![Respiro Sicilia](bilder/hero.jpg)](https://abuelia81.github.io/RespiroSicilia/)

Organisator: [Bestellliste & Abrechnung](https://abuelia81.github.io/RespiroSicilia/runde.html)

Bestellrunde einer Einkaufsgemeinschaft für Zitrusfrüchte, Mandeln und Olivenöl aus Sizilien.

- `index.html`: Bestellseite mit Kisten A/B/C, Produkten, Produzenten, Über mich und Bestellformular
- `runde.html`: für den Organisator, mit Bestellliste, Einkaufsliste je Produzent, Packliste und Abrechnung
- `runde.js`: alle Einstellungen (Stichtag, Kisten, Preise, Bankdaten, Produzenten)
- `bilder/`: Fotos von Produkten, Kisten und Produzenten-Landschaften, erzeugt mit Gemini (Symbolbilder)
